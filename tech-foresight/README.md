# Глобальный форсайт технологической эволюции (до 2050)

Демонстрационный образец (proof-of-concept) одностраничной веб-платформы
комплексной технологической аналитики по ТЗ «Платформа комплексной
технологической аналитики». Интерфейс на русском, тёмная тема по умолчанию.

## Запуск

Внешних зависимостей и сборки нет — чистый HTML/CSS/JS. Нужен только Python
(для локального статического сервера, чтобы браузер корректно загружал модули данных):

```bash
cd tech-foresight
python3 serve.py
```

Затем откройте <http://localhost:8780/index.html>.

> Файл можно открыть и напрямую (двойным кликом по `index.html`) — все скрипты
> подключаются обычными `<script>`-тегами без ES-модулей.

## Что реализовано

Все критерии готовности из раздела 9 ТЗ:

- **Вкладка «Обзор / Карта эволюции»** — конвейер-воронка S1→S6 со счётчиками и
  потоками, ландшафт конвергенции (граф), распределение по доменам, выбор
  технологии с прослеживанием её траектории по слоям и критериями перехода.
- **«Каталог технологий»** — 50 технологий, поиск, фильтры (слой, домен,
  аудитория, тип связи), сортировка, переключение сетка/таблица, детальная
  карточка (описание, следующий рубеж, присутствие по слоям, связи с переходами,
  аудитории, разрезы).
- **6 вкладок слоёв S1–S6** — назначение, критерий перехода, сущности,
  технологии на слое, ключевые вопросы, аудитории, источники (описательно),
  связи со смежными слоями и **3–4 переключаемых варианта визуализации** на слой.
- **«Аналитические разрезы»** — 16 разрезов, фильтры, детальная карточка с
  вопросами, аудиториями, **1–5 переключаемыми визуализациями**, источниками
  (описательно) и выводами по каждой аудитории.
- **«Системные вопросы»** — 6 категорий глобального уровня с переходами к
  релевантным разрезам и слоям.
- **Фильтр аудитории** (7 аудиторий) меняет акценты: порядок визуализаций и
  контекстные подсказки во всех вкладках.
- **Тёмная/светлая темы**, сохранение настроек в `localStorage`, сброс к
  начальным данным.

### Библиотека визуализаций (`js/viz.js`)

Переиспользуемые SVG-компоненты с общим tooltip, отрисованные на демонстрационных
данных: воронка/конвейер, санки, граф/сеть (force-layout), тепловая карта,
пузырьковая, диаграмма рассеяния, матрица квадрантов, мультилиния, стек-область,
столбчатая, каскадная (waterfall), торнадо-чувствительность, радар,
хорд-диаграмма, дерево, таймлайн, концентрические круги масштабов, веер
сценариев, причинно-петлевая диаграмма, гео-карта.

## Структура

```
tech-foresight/
├── index.html            # каркас: шапка, sticky-вкладки, панель
├── serve.py              # локальный статический сервер (порт 8780)
├── css/styles.css        # дизайн-система: токены тем, цвета слоёв/аудиторий
├── data/
│   ├── technologies.js   # seed: 50 технологий, рёбра конвергенции, домены
│   └── layers_cuts.js    # seed: 6 слоёв, 7 аудиторий, 16 разрезов, типы связей
└── js/
    ├── utils.js          # DOM-хелперы, drawer, детерминированный ГПСЧ
    ├── store.js          # состояние, localStorage, производные демо-метрики
    ├── viz.js            # библиотека визуализаций (SVG)
    ├── tabs.js           # рендеринг вкладок + диспетчер визуализаций
    └── app.js            # шапка, вкладки, фильтр аудитории, маршрутизация
```

## Ограничение демонстрационной стадии

Сбор и парсинг данных **не реализуются**. Источники и механизмы обновления
показаны как справочные метаданные с пометкой «описание, реализация на целевой
стадии». Синтетические метрики (инвестиции, патенты, TAM и т.д.) вычисляются
детерминированно из seed для наглядности графиков и не являются реальными.
